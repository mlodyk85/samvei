# Samvei Scandinavia

MVP aplikacji carpooling dla Norwegii, Szwecji i Danii.

## Android APK
Plik instalacyjny jest budowany automatycznie przez GitHub Actions z paczki `samvei-scandinavia-mvp.zip`.

Funkcje MVP:
- pasażer zgłasza trasę A → B,
- kierowca publikuje trasę i maksymalny objazd,
- dopasowanie pasażera „po drodze”,
- Supabase Auth i baza,
- blokada biometryczna,
- integracja Stripe przygotowana pod kartę / Google Pay / Apple Pay.
